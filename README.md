# 🎯 GATE Mock Exam Simulator

A feature-rich, high-fidelity Single Page Application (SPA) designed to replicate the interface and intense environment of the actual GATE (Graduate Aptitude Test in Engineering) examination. Built to test both frontend logic and complex state management.

## ✨ Key Features

* **Advanced Quiz Engine:** Dynamic question loading, smooth navigation (Previous/Next), and instant answer tracking.
* **Smart Exam Tools:** Native "Mark for Review" status and a strict per-question countdown timer to simulate real exam pressure.
* **Post-Exam Analytics:** An interactive results dashboard featuring subject-wise analysis and a simulated leaderboard.
* **Modern Authentication:** Secure, interactive user flows for Sign Up, Login, and Logout.
* **Premium UI/UX:** A fully responsive, mobile-friendly design sporting a sleek glassmorphic dark theme.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Glassmorphism styling), JavaScript (ES6+)
* **Architecture:** Component-based SPA (Single Page Application)
